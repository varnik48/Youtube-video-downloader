YouTube Video Downloader 🎥⬇️

This is a simple YouTube Video Downloader built with Python using the pytube library.
It allows you to quickly download YouTube videos in their highest resolution by just providing the video URL.

🚀 Features

Fetches and displays the video title before downloading

Downloads videos in the highest available resolution

Simple and beginner-friendly Python script

🛠️ Requirements

Python 3.x

pytube
